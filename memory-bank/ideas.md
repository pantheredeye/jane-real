## Off-the-wall (ranked roughly by gut-feel impact)

- Open-house Sunday crawler — scout inventory between client showings
- AirPods press-and-hold voice memos via iOS audio session
- "Rep your vibe" client memento PDF after 5+ showings (marketing gold)
- Cross-source price arbitrage (Zillow vs Redfin vs Realtor diffs → conversation hooks)
- Anonymous heatmap: "shown by N other agents this week"
- Forwarded-text intake (MMS gateway → LLM parse → draft route)
- Photo / screenshot OCR intake (clients send screenshots, common pattern)
- Property-briefing-as-podcast between drives (TTS)
- Apple Wallet pass per route day
- iMessage app extension (clients send properties as iMessage payloads)
- Lock screen / Live Activity / Dynamic Island ("Next: 123 Oak — 8 min")

## Operational

- Twilio forwarding number for web-side text-to-route intake
- ShowingTime outbound: generate copy-paste-able showing-request texts per listing agent
- Daily prep agent: morning text with day's plan + weather + traffic + listing-status diffs
- Triage agent: client sends 12 links, agent scores against client preferences, suggests cut
- "Running late by 15" one-tap shift, notifies stakeholders
- "Skip & reflow" when a property is unavailable on arrival
- Pre-flight checklist before tour-start ("8 stops, 4h32, 3 unconfirmed, ends 11:42, weather X")
- Route templates ("typical Saturday morning") — most agents have 2–3 patterns
- Route variations / drafts — tab strip + diff badge, compare side-by-side desktop
- Property-status pills beyond v1 (`geocoded` / `confirmed` / `scouted`) — Linear discipline: only non-default states render
- Showing-window visualization — listing-agent-only-1-3pm renders as hatched constraint band in time gutter; drag-within-window snapping
- Visible undo stack UI ("undo last 3 changes") after paste-storms or cascade reflows
