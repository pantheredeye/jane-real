Start-of-session orientation.

Read in order:
1. `NORTH_STAR.md` (project vision)
2. `memory-bank/active-context.md` (where we left off)
3. The latest entry in `memory-bank/progress.md` (last session's shipped work)

Then summarize, in 10–15 lines max:
- Current 60-day primary focus
- What was decided last session
- The next 1–3 concrete steps
- Any open questions awaiting the user

End with one short prompt asking what the user wants to work on this session.

Be terse. No filler. The user reads this to remember context — they don't need narrative.
